# Security Policy

## Supported versions

Security fixes target latest published release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/bvolpato/brrragent/security/advisories/new).
Do not open public issue for undisclosed vulnerabilities.

Include affected version, impact, reproduction steps, and any suggested fix.
Redact credentials, access tokens, private prompts, and customer data.
